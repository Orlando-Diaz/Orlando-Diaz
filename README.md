## Proyectos

### Mercadia: marketplace de productos
Los usuarios publican y compran productos, dejan reseñas y pagan con un flujo de pago simulado. Tiene carrito, filtros de búsqueda, historial de compras y un panel de administración de categorías.
- **Stack:** Java, Spring Boot, Spring Security + JWT, PostgreSQL, Angular, Docker, JUnit
- [Demo](https://marketplace-orlandodiaz.vercel.app/) · [Backend](https://github.com/Orlando-Diaz/marketplace-backend) · [Frontend](https://github.com/Orlando-Diaz/marketplace-frontend)

### Fade: agenda y reservas para barberías
El cliente reserva su turno desde el celular, sin crear cuenta. El dueño ve su agenda en un calendario mensual, confirma o cancela citas y administra servicios, barberos y horarios. Cada barbería tiene su enlace y un código QR.
- **Stack:** .NET 10 (ASP.NET Core, EF Core), PostgreSQL, Angular, JWT, Docker, xUnit
- [Demo](https://agenda-barber-liard.vercel.app/) · [Código](https://github.com/Orlando-Diaz/agenda-barber)

### Bolsillo: finanzas personales para el teléfono
App para llevar ingresos y gastos por cuenta y verlos en gráficas. Se instala en el celular como una PWA.
- **Stack:** Python, FastAPI, JWT, PostgreSQL, PWA
- [Demo](https://mis-finanzas-hhte.onrender.com/) · [Código](https://github.com/Orlando-Diaz/gestor-finanzas)

Los servidores de las demos son gratuitos y se duermen: la primera carga puede tardar hasta un minuto.

### En la universidad
**InventoryRx**: sistema de gestión para una droguería, hecho en equipo con arquitectura hexagonal. Maneja inventario por lotes y vencimientos, pedidos con prescripciones médicas y cinco roles con Spring Security.
- **Stack:** Spring Boot, Angular, PostgreSQL, JUnit, Scrum con Jira
- [Código](https://github.com/Dan17i/softwareDrogueria)
