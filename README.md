## 🚀 Proyectos destacados

### [InventoryRx](https://github.com/Dan17i/softwareDrogueria) — Sistema de gestión para droguería
Plataforma web para gestión farmacéutica, desarrollada en equipo con **arquitectura hexagonal**.
- Control de inventario con lotes, fechas de vencimiento y alertas de stock mínimo.
- Gestión de pedidos con validación de disponibilidad y prescripciones médicas.
- Seguridad con Spring Security, cinco roles y cifrado BCrypt.
- **Stack:** Spring Boot · Angular · PostgreSQL · JUnit · Scrum (Jira)

### [Plataforma de Reportes Ciudadanos](https://github.com/Orlando-Diaz/proyecto_avanzada)
Aplicación web full stack para reportar incidentes ciudadanos con geolocalización.
- Autenticación con activación por correo, recuperación de contraseña y roles (usuario y moderador).
- Mapas con Mapbox, imágenes en la nube y notificaciones por correo.
- **Stack:** Spring Boot · Angular · MongoDB · Mapbox · JUnit
